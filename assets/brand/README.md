# Approved Iran Yaraq assets

The operator's `logoType.png` and `iraniyaragh_favicon.ico` (2026-11-04)
are preserved byte-for-byte as `source/wordmark.png` and `source/favicon.ico`.
`source/mark.png` is the ICO's original largest embedded PNG (256 × 256),
extracted without redrawing or stretching. Manifest source hashes identify the inputs.

`node scripts/prepare-brand-assets.cjs` creates transparent WebP UI images,
PNG browser/touch icons and the print PNG, preserving the wordmark aspect ratio.
The supplied seven-size ICO is copied unchanged to both apps' public root and
brand directory. `--check` verifies generated bytes and manifest in both apps.
UI image URLs have a revision query to invalidate old browser caches; crawler-facing
favicon URLs remain stable. No CDN or generated replacement artwork is used.

Use the logotype at identity boundaries: storefront header/footer, navigation
header, login header, Admin shell and invoice header. Do not insert logos into
sentences, product section labels, supplier name fields or copyright text.
The hero slider has no brand badge; its slide copy and links remain available.
The image alternative is the actual brand name; link labels describe their destination.
Page titles, descriptions and structured identity retain the textual brand name.
There is no repeated hidden keyword copy added for ranking.

Admin authentication/sidebar and invoice UI/print reuse the same assets. Admin
URLs include its configured base path. Seller names/contact/tax and financial totals
still come from immutable issued snapshots. Existing stored PDF artifacts are not
rewritten by branding changes.

Implementation references:
- https://www.w3.org/WAI/tutorials/images/functional/
- https://developers.google.com/search/docs/appearance/google-images
- https://developers.google.com/search/docs/appearance/favicon-in-search
- https://developers.google.com/search/docs/essentials/spam-policies#hidden-text-and-link-abuse

New private PDFs use template v3 with the new hash-pinned logo. Templates v1/v2
load the original archived print PNG for pending legacy jobs. Existing artifacts
retain their original template identity and bytes. The legacy logo is never
referenced by the current storefront UI.
